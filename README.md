### 🚀 CS50 Journey: Lecture 0 (Scratch)
​
### Project 1: Clinical Triage Bot
​Instead of a basic "Hello World," I built a functional triage program using Scratch that applies medical logic to patient inputs.
​
### Key Features I Implemented:
​**Dual-Threshold Logic:** I used an OR operator to detect both Hyperthermia (>38°C) and Hypothermia (<36°C).
​
**Interactive Input:** The program uses Sensing blocks to ask for the patient's name and age to personalize the interaction.
​
**Multi-Sensory Output:** I integrated Text-to-Speech so the bot verbally communicates the clinical advice.
​
**Dynamic Strings:** I used Join blocks to combine static text with user variables for a more human feel.
​


### What I Learned:
​**Algorithms:** Clinical decision-making is essentially a series of If/Else statements.
​
**Boolean Operators:** How to use OR to check for multiple clinical conditions at once.
